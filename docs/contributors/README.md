# Per-contributor AI instructions

Each person maintains:

```text
docs/contributors/<your-name>/AI_INSTRUCTIONS.md
```

Use your GitHub username or first name — just stay consistent.

## Setup

1. Copy [`_TEMPLATE_AI_INSTRUCTIONS.md`](_TEMPLATE_AI_INSTRUCTIONS.md) to your folder and rename/edit.
2. From [`../ai/`](../ai/), paste in the **role** sections you own (discover, filter/hand-off, CI/tests, docs/report).
3. Add any personal preferences (tone, tools, things the AI should never do).
